Set up in five minutes.

Install with npm, create the wallet in your terminal, set your rules, and connect your agent host.

Get started

Five minutes, and a small amount of USDG.

The key is created on your computer and encrypted with your passphrase. Fund the wallet with only what you are willing to let an agent spend.

Until you turn it on, every payment waits for you, including the ones inside your rules.

# install (Node.js 22.12 or newer)
npm install -g https://github.com/reinpay/reinpay/archive/refs/heads/main.tar.gz

# in your own terminal
reinpay init
reinpay payee add "Weather API" 0xRecipient --tokens=USDG
reinpay rule daily USDG 25
reinpay rule approve-above USDG 5
reinpay address            # fund this with a small amount

# connect your agent host, for example Claude Code
claude mcp add --scope user reinpay -- reinpay mcp

# later
reinpay pending
reinpay approve RP-00042
Default ruleUSDGETH
Daily budget250.005
Max per payment100.002
Asks you above50.001
Repeat guard10 minutes
Tools for the agent

Eleven MCP tools. None of them can approve.

wallet_statusAddress, ETH and USDG balances, today's budget left per token, the rules
get_rulesThe rules and the payees the agent may pay
request_paymentAsk for one payment; returns the decision and the receipt
get_receiptOne receipt by id
list_receiptsRecent receipts, optionally by status
verify_receiptRead a sent payment back from the chain and check it against its receipt
spending_reportSent, waiting and blocked per day and token, top payees
review_rulesSuggestions for the owner's rules, each with the command to run
read_payment_linkRead an ethereum: payment link: who, how much, and whether the payee is on the list
check_paymentDry run: what would happen to a payment now, without recording anything
freeze_walletStop every payment until the owner unfreezes it. The agent can freeze, never unfreeze

FAQ

Questions owners ask first.

Do I need to trust this website?

No. The website never sees a key. The wallet runs on your computer; the app page only reads public balances and, if you choose, asks your browser wallet to send a transfer you review first.

Which agent hosts work?

Any MCP host that runs a local command: Claude Code, Cursor, Codex, Windsurf, VS Code and others. Run reinpay mcp as a stdio server.

What can it pay in?

USDG and ETH on Robinhood Chain mainnet (chain id 4663) are built in. You can add other ERC-20s with reinpay token add; each one must be verified on Sourcify, and nothing is spent until you set its budget.

Can I run more than one agent?

Yes. Give each agent its own wallet with --profile=<name>: separate key, rules, payees and receipts, so one agent cannot spend another's budget.

What happens if my agent loops?

The repeat guard holds the same payee, token and amount within 10 minutes for you, and the daily budget caps the rest.

How much should I put in?

Only what you are willing to let an agent spend. Until you turn on autosend, every payment waits for you anyway.

What if something edits my config file?

Since 0.5.0 your rules and payees are sealed with your wallet key. If config.json is changed outside Reinpay, for example a payee added by another program, nothing is signed until you check reinpay rules and run reinpay seal.

How do I know a payment really went through?

Run reinpay verify RP-…. It reads the transaction back from Robinhood Chain and checks that it succeeded, came from your wallet, and paid that payee that exact amount of that token. Your agent can do the same with the verify_receipt tool.

Something is not working. Where do I start?

Run reinpay doctor. It checks Node.js, the RPC, the chain, the wallet, the seal, the unlock, ETH for fees, payees and budgets, and says what to do for anything that is off.

How do I stop everything right now?

Run reinpay freeze. Every request is blocked, autosend stops and approvals are refused until you run reinpay unfreeze in your terminal. The wallet also freezes itself if the agent is blocked 5 times in 10 minutes.

Can I prove what my agent spent?

Yes. reinpay statement writes every sent payment in a period to a file signed with your wallet key. Whoever you send it to runs reinpay statement check: it confirms your wallet signed it, that nothing was changed, and that every payment is on Robinhood Chain as written.

How do I move Reinpay to a new computer?

Run reinpay backup on the old one. It writes your key (still encrypted with your passphrase), rules, payees and receipts to one file. Install Reinpay on the new computer and run reinpay restore file.json. Keep that file as safe as the key itself.

Can my team share one payee list?

Yes. reinpay payee export writes your payees to a file signed with your wallet key. A teammate runs reinpay payee import: it shows who signed it and adds only payees that pass the usual checks, skipping lookalike addresses and token contracts.

Can I give different kinds of spending their own budget?

Yes. Put payees in categories with reinpay payee category, then set reinpay rule category compute daily USDG 10. Every payment must fit both your overall daily budget and its category's. You can also set payment hours and a cap on payments per hour.

Can Reinpay pay a subscription every month?

Yes. reinpay schedule add "Weather API" 5 USDG monthly, then run reinpay schedule run from cron. Each payment still goes through every rule and the mainnet simulation, and waits for you unless autosend is on.

Can I set a budget in dollars?

Yes. reinpay rule usd daily 50 caps a day at 50 dollars across USDG and ETH together, and reinpay rule usd max 20 caps any single payment. ETH is priced from two WETH/USDG pools on Robinhood Chain; if they disagree by more than 2%, the payment is blocked rather than guessed.

I run several agents. Can I see them all?

Give each its own wallet with --profile=<name>, then reinpay profiles --status shows them all on one screen, and reinpay freeze --all stops every one at once.

Can I try it before I put money in?

Yes. reinpay sandbox runs five requests through the real rules and real mainnet simulations with a throwaway wallet and a pretend balance. Nothing is signed or sent.

Can two people approve big payments?

Yes. reinpay rule cosign 0xADDRESS USDG 50: above 50 USDG, a payment needs your approval and a signature from that second address over that exact payment.

How do I add Reinpay to Cursor or VS Code?

Run reinpay connect cursor (or claude, vscode, windsurf, codex). It prints the exact snippet; reinpay mcp --check confirms the server starts.

Is it free?

Yes. Open source under MIT. You pay only the network fee in ETH for each payment.
