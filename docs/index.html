Set up in five minutes.

Install with npm, create the wallet in your terminal, set your rules, and connect your agent host.

Get started

Five minutes, and a small amount of USDG.

The key is created on your computer and encrypted with your passphrase. Fund the wallet with only what you are willing to let an agent spend.

Until you turn it on, every payment waits for you, including the ones inside your rules.

# install (Node.js 22.12 or newer)
npm install -g https://github.com/reinpay/reinpay/archive/refs/heads/main.tar.gz

# in your own terminal
reinpay init
reinpay payee add "Weather API" 0xRecipient --tokens=USDG
reinpay rule daily USDG 25
reinpay rule approve-above USDG 5
reinpay address            # fund this with a small amount

# connect your agent host, for example Claude Code
claude mcp add --scope user reinpay -- reinpay mcp

# later
reinpay pending
reinpay approve RP-00042
Default ruleUSDGETH
Daily budget250.005
Max per payment100.002
Asks you above50.001
Repeat guard10 minutes
Tools for the agent

Five MCP tools. None of them can approve.

wallet_statusAddress, ETH and USDG balances, today's budget left per token, the rules
get_rulesThe rules and the payees the agent may pay
request_paymentAsk for one payment; returns the decision and the receipt
get_receiptOne receipt by id
list_receiptsRecent receipts, optionally by status
Commands

Everything you run in your terminal.

reinpay init [--import]Create or import the encrypted wallet. Terminal only.
reinpay addressPrint the wallet address
reinpay statusBalances, budget left today and the rules
reinpay rule daily|max|approve-above <token> <amount>Set a rule for USDG or ETH
reinpay rule repeat-guard <minutes>Hold repeats for that long (0 turns it off)
reinpay payee add <name> <0xaddress> [--tokens=USDG,ETH]Add a payee
reinpay payee list | remove | off | onManage payees
reinpay pendingPayments waiting for you
reinpay approve | reject <RP-id>Decide a waiting payment
reinpay receipts [--status=sent] [--json]Everything, newest first
reinpay autosend on|offSend payments inside every rule without asking (needs unlock)
reinpay unlock | lockStore or remove the passphrase file
FAQ

Questions owners ask first.

Do I need to trust this website?

No. The website never sees a key. The wallet runs on your computer; the app page only reads public balances and, if you choose, asks your browser wallet to send a transfer you review first.

Which agent hosts work?

Any MCP host that runs a local command: Claude Code, Cursor, Codex, Windsurf, VS Code and others. Run reinpay mcp as a stdio server.

What can it pay in?

USDG and ETH on Robinhood Chain mainnet (chain id 4663). Budgets are per token and per local calendar day.

What happens if my agent loops?

The repeat guard holds the same payee, token and amount within 10 minutes for you, and the daily budget caps the rest.

How much should I put in?

Only what you are willing to let an agent spend. Until you turn on autosend, every payment waits for you anyway.

Is it free?

Yes. Open source under MIT. You pay only the network fee in ETH for each payment.

Try your rules before you install.
