Install

Install Reinpay in a few minutes.

Everything runs on your own computer. You need Node.js, a terminal, and a small amount of USDG and ETH on Robinhood Chain.

  1. Install Node.js

    Download the LTS installer from nodejs.org and run it with the default options. Then open Command Prompt (Start menu, type cmd).

    Download the LTS installer from nodejs.org, or run brew install node if you use Homebrew. Then open Terminal.

    Install Node.js 22.12 or newer from nodejs.org or with nvm, then open a terminal.

    Check the version. It must be 22.12 or newer.

    node --version

  2. Install Reinpay

    One command, straight from the open source code on GitHub.

    npm install -g https://github.com/reinpay/reinpay/archive/refs/heads/main.tar.gz
    On Windows, if PowerShell says running scripts is disabled, use Command Prompt instead. On macOS or Linux, if you get a permission error, put sudo in front of the command.

  3. Check it worked

    It prints the version.

    reinpay --version
    0.8.0

  4. Create your wallet

    Reinpay creates a new key on your computer and asks you for a passphrase. The key is encrypted with it and kept in .reinpay in your home folder. Write the passphrase down somewhere safe: without it the key cannot be opened.

    reinpay init
    Already have a key you want to use? Run reinpay init --import instead.

  5. Add a payee and your rules

    Who the agent may pay, and how much. Replace the address with the payee's real one.

    reinpay payee add "Weather API" 0xPayeeAddress --tokens=USDG
reinpay rule daily USDG 25
reinpay rule max USDG 10
reinpay rule approve-above USDG 5
reinpay rules
    Not sure which numbers to pick? Try them first in the Rule builder, which writes these commands for you.

  6. Connect your agent

    For Claude Code:

    claude mcp add --scope user reinpay -- reinpay mcp

    Any other MCP host (Cursor, Codex, Windsurf, VS Code and others): add a stdio server with the command reinpay mcp.

  7. Fund it with a small amount

    Print the wallet address, then send a little USDG for payments and a little ETH for network fees on Robinhood Chain.

    reinpay address
    You can check the balance and send funds from your browser wallet on the Fund tab of the app.

  8. Approve what waits for you

    Until you turn on autosend, every payment waits for you, even inside your rules.

    reinpay pending
reinpay approve RP-00001
Later

Update or remove.

UpdateRun the same install command again. Your wallet, rules and receipts stay. Coming from 0.4 or older? Run reinpay seal once after updating.
npm install -g https://github.com/reinpay/reinpay/archive/refs/heads/main.tar.gz
reinpay seal
RemoveRemoves the program. Your encrypted key stays in .reinpay until you delete that folder yourself.
npm uninstall -g reinpay

Installed? Open the app and read your wallet.
