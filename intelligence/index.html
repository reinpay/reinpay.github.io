What it watches

Three sources, all public.

01

The token

Supply, the dead address and every Transfer to it, read from the REINPAY contract with plain JSON-RPC.

02

The holders

Every balance, rebuilt from the token's own Transfer logs. Pools and contracts count too.

03

The lab

Every hour, Reinpay's rules are run against test requests on throwaway wallets, with real mainnet simulations.

04

The schedule

GitHub Actions runs the readers every hour from the public code. Anyone can check the scripts and the commits.
