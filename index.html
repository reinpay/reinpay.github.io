Wallet for AI agents · Robinhood Chain mainnet

Give your agent money. Keep the reins.

Reinpay is a wallet your agent can ask to pay, but that only pays inside your rules: a daily budget, a list of payees, a max per payment, and a line above which it asks you first. Every payment is simulated on mainnet before anything is signed, and every request leaves a receipt.

How it decides

Every request runs the same checks, in the same order.

The first check that fails decides, and the receipt names it. Hard limits block outright. Softer ones hand the payment to you. Only a payment that passes all of them goes on to the simulation.

  1. The payee is on your listSwitched on, and allowed to receive that token. No fuzzy matching on names.else blocked
  2. The amount fits the max per paymentYour max for the token, and the payee's own max if you set one.else blocked
  3. Today's budget has roomCounting what was sent today and what is still waiting for you. Per token, per local calendar day.else blocked
  4. It is not a repeatSame payee, token and amount within 10 minutes looks like a loop.else asks you
  5. It is under your approval lineAbove the line, the payment waits for reinpay approve.else asks you
  6. The simulation matcheseth_simulateV1 on Robinhood Chain mainnet must show exactly one transfer leaving the wallet: that amount, that token, to that payee. The wallet must also cover the network fee.else blocked
Who can do what

The agent can ask. Only you can say yes.

The commands that approve payments, change rules or add payees refuse to run without a real terminal, so an agent driving a shell cannot reach them either.

Your agent, over MCP

  • Read the wallet's balances and today's budget left
  • Read the rules and the payee list
  • Ask for a payment, with a memo
  • Read its receipts

You, in your terminal

  • Approve or reject what is waiting
  • Set budgets, max per payment and the approval line
  • Add, remove or switch off payees
  • Turn on sending without asking, for payments inside every rule
Get started

Five minutes, and a small amount of USDG.

The key is created on your computer and encrypted with your passphrase. Fund the wallet with only what you are willing to let an agent spend.

Until you turn it on, every payment waits for you, including the ones inside your rules.

# install (Node.js 22.12 or newer)
npm install -g https://github.com/reinpay/reinpay/archive/refs/heads/main.tar.gz

# in your own terminal
reinpay init
reinpay payee add "Weather API" 0xRecipient --tokens=USDG
reinpay rule daily USDG 25
reinpay rule approve-above USDG 5
reinpay address            # fund this with a small amount

# connect your agent host, for example Claude Code
claude mcp add --scope user reinpay -- reinpay mcp

# later
reinpay pending
reinpay approve RP-00042
