RP·OS PROGRESS

Watch Reinpay grow.

One release at a time, each with a short video of the real thing: the command, the mainnet simulation and the decision.

Every video is real output from a run on Robinhood Chain mainnet, replayed line by line. The demo wallets are throwaway, and nothing in them is signed or sent.

v0.52.0

x402 check

reinpay x402 check reads what an x402 service asks to be paid: how much, which token, who gets paid, on which network. Your rules and a mainnet dry run decide. Nothing is paid.

v0.50.0

Selftest

reinpay selftest runs Reinpay's own tests on your computer, each in a temporary home, so your wallet is never touched. You do not have to take our word for it.

Changelog →
v0.49.0

Agent prompt

reinpay prompt writes instructions to paste into your agent: how to use the Reinpay tools safely, and your rules in plain words.

Changelog →
v0.48.0

Rules in plain words

reinpay rules --plain prints every rule as a sentence, one line per payee. The agent gets the same sentences in get_rules.

Changelog →
v0.47.0

A payee's own approval line

reinpay payee limit ask-above gives one payee a stricter approval line; above it, payments to that payee wait for you.

Changelog →
v0.46.0

Balance share

reinpay rule balance-share keeps one payment at or below a share of the wallet balance, read from the chain, and fails closed.

Changelog →
v0.45.0

Payments per day

reinpay rule per-day caps how many payments can be sent or waiting in one day, across every payee and token.

Changelog →
v0.44.0

Rules files

reinpay rules export writes your rules to a signed file; reinpay rules import checks the signature, shows every change and asks for yes.

Changelog →
v0.43.0

Blocked memo words

reinpay rule memo-block refuses any request whose memo contains a word you block, like airdrop or claim. The agent never sees the list.

Changelog →
v0.42.0

Payee cooldown

reinpay payee cooldown sets a minimum time between payments to one payee, with the time the next one can be asked for.

Changelog →
v0.41.0

Payee rename

reinpay payee rename keeps the address, limits and proof, moves the schedules, and shows in the rules history as one line.

Changelog →
v0.40.0

Rule templates

reinpay rules template prints a ready rule set, cautious, balanced or open, compared with yours and as the commands to run.

Changelog →
v0.39.0

Why

reinpay why replays a past payment rule by rule, with the rules sealed at the time, and checks it matches the receipt.

Changelog →
v0.38.0

Headroom

reinpay headroom shows, per payee, what the agent could pay right now without you, with your yes, and which rule stops it above that. Worked out by the same rules that decide every payment.

Changelog →
v0.37.0

Approve, dry

reinpay approve --dry runs every check approve makes, fresh now, with a new mainnet simulation, and stops before your key is opened. Nothing is signed.

Changelog →
v0.36.0

Rules history

Every change to the rules and payees is recorded before → after, signed with the wallet key and chained. reinpay rules history lists them and catches a file edited by hand.

Changelog →
v0.35.0

Payee add checks first

reinpay payee add runs the payee check on Robinhood Chain before it adds anything: a fresh address asks for yes, a token contract is refused, a lookalike needs the full address typed again.

Changelog →
v0.34.0

Payee check

reinpay payee check reads an address from Robinhood Chain before it becomes a payee: wallet or contract, history, Sourcify and lookalikes, then looks fine, be careful, or do not add.

Changelog →
v0.33.0

Today

reinpay today is one screen for the owner: the budget per token as a bar, what waits for you, what was blocked and why, the next bills and the brakes, with the balance read from the chain.

Changelog →
v0.32.0

Plans

reinpay check --plan checks a whole list of payments in order, as if the agent asked for all of them now: budgets add up, repeats are held, and every payment that passes is simulated on mainnet.

Changelog →
v0.31.0

Why, rule by rule

reinpay check --explain walks through every rule in order with what it found, marks the one that decided, and ends with the real mainnet simulation.

Changelog →
v0.30.0

Stay up to date

reinpay --version --check asks GitHub whether a newer Reinpay is out, and never installs anything by itself. reinpay changelog shows what changed.

Changelog →
v0.29.0

Connect

reinpay connect prints the exact command or config for Claude, Cursor, VS Code, Windsurf or Codex. reinpay mcp --check starts the real server and lists its tools.

Changelog →
v0.28.0

Memo privacy

reinpay redact removes one memo for good and notes it in the receipt history. --no-memos keeps memos out of statements, shares and books.

Changelog →
v0.27.0

Reliable notifications

v0.26.0

Books
